# Algoritmos de busca com Rust

Atividade proposta pelo professor Alexandre Montanha com objetivo de comparar o comportamento dos algoritmos conforme o tamanho do vetor aumenta.

### Códigos implementados

* Busca Sequencial Simples
* Busca Sequencial com Interrupção
* Contagem de ocorrências
* Retorno de todas as posições encontradas
* Geração de vetores de Strings
* Experimentos de desempenho
